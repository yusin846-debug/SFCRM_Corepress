# 설비 건강도는 숫자 점수가 아니라 상태 밴드로 표현한다

포털 홈이 자산마다 가짜 90점을 보여주던 문제(운전 중이면 무조건 90, 화면마다 로직이 달랐음)를 없애기 위해, 건강도를 5단계 밴드(양호 / 관찰 / 점검 필요 / 교체 필요 / 데이터 확인 중)로만 표현하고 `CpAssetHealthController` 한 곳에서 판정한다. 0~100 점수도 검토했으나, 합의된 실제 기준(누적 운전시간 ≥ 오버홀 주기 × 3, 활성 보증 없음=유상, Obsolete, Sales Alert)이 전부 boolean이라 연속 점수는 근거가 없고 오히려 신뢰를 떨어뜨린다. 포털 홈·보유 설비 목록·설비 상세가 모두 이 컨트롤러 결과를 사용해 자산별 밴드가 세 화면에서 일치한다.

## Considered Options

- **상태 밴드만 (채택)**: 합의 기준과 1:1 대응, 화면 간 일관성 확보가 쉬움.
- **밴드 + 파생 점수**: 교체 25 / 점검 55 / 관찰 75 / 양호 92 식. 숫자가 다시 "왜 이 값?" 질문을 부름.
- **오버홀 사이클 진척률(%) 게이지**: `누적운전 / 오버홀주기`. 보증·폐기 신호를 담지 못해 반쪽짜리.

## Consequences

- 삼양중공업(테스트 계정)은 시드 데이터상 12대 중 다수가 "교체 필요"로 뜬다 — 의도된 동작이며 데모(대한케미컬)에는 영향 없다.
- "건강 점수" 문구·필드를 쓰던 기존 화면 텍스트를 전부 밴드 라벨로 교체해야 한다.
