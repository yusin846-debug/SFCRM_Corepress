# Product, Asset, 데모 지식의 경계를 분리한다

CorePress Agentforce는 Product를 장비 모델의 구조화된 기준 원천으로, Asset을 고객 보유 장비의 기준 원천으로 사용하고, 데이터 라이브러리 문서는 Product 사실을 검색 가능한 설명으로 보강하는 PoC 자료로만 사용한다. 문서가 실제 제조사 매뉴얼로 오인되는 위험과 Product 변경 시 정보가 어긋나는 위험을 줄이기 위해 모든 생성 문서에 가상 정보 표시를 넣고, 충돌 시 Product/Asset을 우선하며, 위험한 분해·수리 절차와 임의 안전 수치는 생성하지 않는다.
